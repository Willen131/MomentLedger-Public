# 刻记（MomentLedger）孤独摇滚美化版 · Skin Pack (`v2.5.22`)

完全离线、零网络权限的 Android 本地记账应用 — 结束乐队（孤独摇滚）主题与伪 Live2D 桌宠定制分支。

- **当前分支**：`skin-pack`（孤独摇滚美化包 + 角色桌宠版）
- **当前版本**：`v2.5.22`（`versionCode = 31`）
- **最低系统**：Android 8.0（API 26），`compileSdk = 35` / `targetSdk = 35`
- **APK 直下**：[`release/刻记-孤独摇滚版-v2.5.22.apk`](./release/%E5%88%BB%E8%AE%B0-%E5%AD%A4%E7%8B%AC%E6%91%87%E6%BB%9A%E7%89%88-v2.5.22.apk)
- **原生极简版**：如需无主题美化与桌宠的纯净原版，请切换至 [`main`](../../tree/main) 分支。

## 美化与桌宠特色

- **全套孤独摇滚视觉主题**：樱花粉账本 + 蓝黄双色方块书扣自适应图标、磨砂票根卡片、角色专属配色与预算提醒插画。
- **四位角色伪 Live2D 悬浮桌宠**（后藤一里 / 山田凉 / 伊地知虹夏 / 喜多郁代）：
  - 基于原生 Canvas `28×28` 分片刚体 LBS 连续网格蒙皮与两级弹簧物理，零裂缝不撕裂、支持 30/60fps 自适应省电。
  - 支持三态独立眨眼与单眼 Wink、12 种角色专属性格微动作、360° 矢量粒子与互动气泡台词。
  - 支持悬浮大小、弹出卡片大小（50%–150% 实时预览）、物理弹性与灵敏度、以及 **0%–100% 无极精细调节的角色点按触感震动**。
- **包含主干全部核心记账能力**：离线 PP-OCRv5 识账、一键识屏、智能商户/渠道/自定义分类推理、微信/支付宝/银行 PDF 账单导入去重与多维统计预算。

## 本地构建

需要 JDK 17、Android SDK 35 与 Android Build Tools 35.0.0。配置 `ANDROID_HOME` 或在项目根目录添加本地 `local.properties` 后运行：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```
